# Proposal

## Why

采购管理（4.2）是尚未落地的新域，菜单 M2-1-1/2/4（自动请购、手工请购、请购审批）均为占位页。规格流程一「需求触发与请购」（FR-4.2-1-1/2）与规则 BR-4.2-07/08/09/10/50、C-4.2-11 定义了完整的 PR 全生命周期，且 S-4.1-01 场景明确「MRP→PR→确认→补充供应商→流转询价」为采购链路起点——PR 不落地，后续询价（2.2）、订单（2.3）无从衔接。上游 MRP 引擎属 4.5 生产计划域（未建），本变更以模拟净算承接其输出语义并预留真实接入桩。

## What Changes

### 功能一：2.1.1 自动请购（模拟 MRP 净算 → PR）

- **页内模拟 MRP 运算**：录入/批量粘贴四类输入（需求量 Demand、现有库存 OnHand、在制 InProcess、在途 Incoming）→ 按 FR-4.5-2-3 公式 `NetReq = Demand − OnHand − InProcess − Incoming` 净算 → 建议列表：
  - `NetReq ≤ 0` → 标「过量供给」不生成 PR（FR-4.5-2-3）
  - 需求日期 < 今天 → 标「异常/逾期需求」（FR-4.2-1-1 异常处理 + FR-4.5-2-5），可生成但带异常标记，通知计划员 = TODO 桩
  - 建议量 < 物料最小订购量 → 按最小订购量调整（FR-4.5-2-6，物料主数据无该字段则跳过，design 记口径）
  - 输入接口留桩：真实需求/供给源（4.5/WMS）落地后替换为直读
- **勾选生成 PR**：单号 `PR-YYYYMMDD-NNN`（按日流水）；PR 行 = 物料、需求数量、需求日期、**预估单价**（询价前判级基数）、需求来源（枚举：工单/计划订单/销售订单/安全库存/模拟 + 来源单号文本）、建议供应商（`erp_mdm_supplier` 下拉，可空）、来源类型=MRP
- **BR-4.2-07 L1**：行物料 `STATUS ≠ '1'`（未发布/停用/归档）→ 阻断 PR 创建，提示物料当前状态
- **确认状态机（待确认 → 已确认）**：
  - 确认可调需求数量与日期，但 **确认量 ≥ 建议量 × 80%**（BR-4.2-08）；低于 80% → 须填调减理由 + 计划员复核标记（L2 降级：页内复核确认，记录复核人）
  - **BR-4.2-50 L3**：生成超 1 个工作日未确认 → 催办标记；超 3 个工作日 → 升级采购经理标记（懒 sweep + 留痕列；推送通知 TODO 桩）
- **分批交付计划行**：一个 PR 行可拆多个交付行（日期+数量，Σ ≤ 需求数量，创建/调整留痕）
- **C-4.2-11 L3 懒 sweep**：需求日期 + 90 天仍未下达 → 自动关闭 PR 行并留痕；手工关闭 MUST 填原因
- **PO 下达桩**：`receivePoAllocation(prLineId, qty)` 接口留桩（Σ 下达 ≥ 需求量 → 行自动关闭，BR-4.2-51 超量阻断预留），下游 2.3 落地后接入
- **补充供应商 → 流转**：已确认行补建议供应商（可空转询价时再定）→ 状态「待询价」（2.2.1 后续消费）

### 功能二：2.1.2 手工请购

- 手工建 PR（同一 PR 实体与单号规则）：需求来源三选一（项目编号/成本中心/内部订单号，成本中心下拉复用 1.1.2 主数据）+ 需求理由说明 + **预算来源三选一**（预算科目/成本中心/内部订单号）+ 预估单价
- **BR-4.2-09 L1**：预算来源为空 → PR 状态置「待预算确认」，阻断流转询价（页面明示解禁条件：补录预算来源后可提交）；物料 Active 校验同款 L1
- 手工 PR 生成后直接进入「待审批」（无需确认步，S-4.2-02）

### 功能三：2.1.4 请购审批（角色分级状态机）

- **判级金额 = Σ(行数量 × 预估单价)**（询价前口径，design 记解释性偏差）
- **分级路由**：金额 ≤ 部门限额 → 部门经理；≤ 总监限额 → 部门经理 → 采购总监；> 总监限额 → 再加 分管副总裁。限额经配置 `app.proc.dept-approval-limit`（默认 50000）/ `app.proc.director-approval-limit`（默认 500000）——项目无参数管理页，沿 `@Value` 配置先例（信用额度比率同款）
- 节点动作：**通过**（进下一节点/已批准）/ **驳回**（必填原因 → 退回申请人修改 → 可重新提交，BR-4.2-1-2 异常处理）
- **BR-4.2-10 L3**：节点停留超 1 个工作日 → 超时标记；超 3 个工作日 → 升级上一级审批人标记（懒 sweep + 留痕；推送/改派 TODO 桩）；审批全记录入审批日志（L5）
- 已批准 → PR 状态「待询价」；审批过程页内辅助信息：物料历史采购价（询价/PO 未落地 → 显示同物料历史 PR 预估价，design 记口径）

### 基础设施

- **迁移 028**：`erp_proc_requisition`（PR 头：单号唯一、来源类型、状态、预算/需求来源三字段、判级金额）、`erp_proc_pr_line`（行）、`erp_proc_pr_delivery_line`（交付计划行）、`erp_proc_pr_approval`（审批任务/日志：节点、角色、动作、原因、超时/升级标记）
- **PR 状态机**（单点守卫矩阵）：`DRAFT? → PENDING_CONFIRM(MRP) / PENDING_BUDGET(手工无预算) / PENDING_APPROVAL → APPROVING → APPROVED → PENDING_RFQ → ROUTED → CLOSED`（+行级 CLOSED）；单据域沿供应商合并口径：**操作日志 + 状态迁移留痕，不套主数据版本快照**
- **outbox** `PROC.PR.CREATED/CONFIRMED/APPROVED/REJECTED/CLOSED` 事件（幂等键 `PR单号:行号或头:vN` 含记录身份，沿 tax-code D3 教训）
- 路由 `/m/2.1.1` `/m/2.1.2` `/m/2.1.4`（2.1.3 紧急采购不在本轮）；写接口 SecurityConfig `proc/requisitions/**` ADMIN 规则（确认/审批动作在 ADMIN 内做，角色细分留后续）

## Capabilities

### New Capabilities

- `mrp-auto-requisition`: 模拟净算（公式、过量/逾期标记、最小订购量调整）、PR 生成（字段模型、BR-4.2-07 Active 阻断、单号规则）、80% 确认卡控与 L2 调减复核、催办/升级标记、分批交付行、90 天懒关闭与手工关闭、PO 反写桩、补充供应商流转
- `manual-requisition`: 手工 PR 创建（需求/预算来源三选一）、BR-4.2-09 待预算确认阻断、直接进审批
- `requisition-approval`: 判级金额口径、三级角色路由与限额、通过/驳回重提、超时提醒升级标记、审批日志、权限口径

### Modified Capabilities

（无——物料/供应商/成本中心主数据仅被只读引用）

## Impact

- 后端：迁移 `028-purchase-requisition.sql`；`com.erp.procurement` 包首建（Controller/Service/DAO × PR+审批）；复用 `MdmItemDao`（状态校验）、`MdmSupplierDao`、`MdmCostCenterDao`、`OutboxPublisher`、懒 sweep 模式
- 前端：`views/proc/{auto-requisition,manual-requisition,requisition-approval}/index.vue`、`api/proc/*.js`、router 三路由；SecurityConfig 追加 proc 写规则
- 不动：2.1.3、2.2.x、2.3.x、4.5 MRP 引擎（桩接口预留）

### 偏差表（规格 vs 当前落地）

| 规格条目 | 本变更口径 | 级别 |
|---|---|---|
| FR-4.2-1-2 分级审批（Flowable 类工作流） | 角色分级状态机 + 懒 sweep 超时标记；推送/自动改派为 TODO 桩+留痕 | L2 降级入偏差表（沿项目基线） |
| FR-4.2-1-1 MRP 自动触发（4.5 引擎输出） | 页内模拟净算（四类输入手录/粘贴），公式与标记语义与 FR-4.5-2 一致；真实源 4.5/WMS 落地后替换 | 解释性口径（上游未建） |
| 判级「金额」 | 预估单价×数量（询价前无实际报价） | 解释性口径（需求已确认） |
| 审批限额参数（规格参数表未列） | `@Value` 配置项默认 5万/50万，无参数管理页 | 解释性口径（沿 @Value 先例） |
| 建议量 < 最小订购量按 MOQ 调整（FR-4.5-2-6） | 物料主数据无 MOQ 字段 → 跳过该微规则 | 范围裁剪 |
| 审批辅助信息「历史采购价格/库存可供量」 | 显示同物料历史 PR 预估价；库存可供量待 WMS | 简化口径 |
| 2.1.3 紧急采购、2.2 询价、2.3 下达 | 不在本轮 | 范围边界 |
