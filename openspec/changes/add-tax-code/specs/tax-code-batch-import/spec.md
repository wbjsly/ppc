# Spec Delta: tax-code-batch-import

## Purpose
税码批量导入（1.6.3）：CSV/粘贴零依赖录入、逐行预检与行级独立提交、公共政策文号回填、同税码区间衔接传导与《导入结果报告》，落实 FR-4.1-3-3 与 BR-4.1-19 在税码域的口径。

## ADDED Requirements

### Requirement: 模板与录入载体
系统 MUST 提供税码导入 CSV 模板下载：表头 `税码编号,税率值,生效日期,失效日期,适用范围,政策文号,计税方式,税率类型` + 说明行（枚举取值、精度、区间衔接规则）；模板由前端生成（含 BOM 头保证中文 Excel 兼容）。录入 MUST 支持两种方式：上传 `.csv` 文件、粘贴表格文本（Tab 或逗号分隔）；解析 MUST 容错 UTF-8 BOM、行内空格、跳过表头/注释/空行，必需列（前 6 列：税码编号/税率值/生效/失效/适用范围/政策文号）不足的行 MUST 标注解析错误而非静默丢弃（后两列计税方式/税率类型可缺省回填）。

#### Scenario: 模板下载
- **WHEN** 点击下载模板
- **THEN** 获得含表头与说明行的 CSV，中文不乱码

#### Scenario: 短行标注
- **WHEN** 粘贴的某行仅 5 列
- **THEN** 该行在预检中标注「列数不足」，不参与提交

### Requirement: 公共字段回填
导入 MUST 支持整批公共「政策文号」：行内政策文号为空时以公共值回填（S-4.1-07 一份政策覆盖多行）；公共值亦为空且行内为空时该行按必填缺失计入失败。计税方式/税率类型列缺省时 MUST 回填 GENERAL/STANDARD。

#### Scenario: 公共文号回填
- **WHEN** 公共政策文号=`税总公告2026年第15号`，5 行行内文号均为空
- **THEN** 预检与提交中 5 行文号均为公共值

### Requirement: 预检（dry-run）
`preview` 查询 MUST 逐行执行且不落库：复用税码维护的全量单行校验（必填、枚举、编号格式、税率精度与矛盾、失效≥生效）+ 区间衔接（BR-4.1-17 传导）：同税码的批内行按生效日排序，依次与存量区间链及批内前序段判定相交/断档，违规行 MUST 标注原因与可操作口径；返回逐行 `{rowNo, valid, reason, normalized}` 供前端红绿预览。同税码批内重复区间 MUST 被后续行标冲突。

#### Scenario: 批内冲突标注
- **WHEN** 批内同税码两行区间相交
- **THEN** 第二行标注相交原因，第一行通过

#### Scenario: 与存量链衔接
- **WHEN** 存量同税码链尾失效日 2026-06-30，批内该税码首行生效日 2026-07-02
- **THEN** 该行标注断档并提示须 ≤ 2026-07-01

### Requirement: 行级提交与结果报告
`batch` 提交 MUST 按行独立执行（BR-4.1-19）：每行独立调用税码创建能力（版本快照与 `MDM.TAXCODE.CREATED` 事件逐行生成），单行失败 MUST 收集原因且不回滚成功行；批次 MUST 上限 500 行（超出 422）。提交响应与页面 MUST 提供《导入结果报告》：总数/成功数/失败数 + 逐行 `{rowNo, result, reason}`（失败行标红），支持报告 CSV 下载。提交前 MUST 建议先执行预检（未预检直接提交亦按同等校验行级拦截）。

#### Scenario: 部分失败不回滚
- **WHEN** 10 行中 2 行区间断档
- **THEN** 8 行发布成功（各含快照与事件），2 行标红给出原因，响应 succeeded=8 failed=2

#### Scenario: 超限阻断
- **WHEN** 提交 501 行
- **THEN** 系统 422 拒绝整批

### Requirement: 权限与页面
批量导入接口 MUST 要求 ROLE_ADMIN（403）；页面挂载于菜单 1.6.3（`/m/1.6.3`，M1-6-3 已注册），流程为 模板 → 录入 → 预检表格 → 确认提交 → 结果报告；成功数 >0 时提供跳转税码维护列表入口。

#### Scenario: 普通用户不可导入
- **WHEN** ROLE_USER 调用批量提交接口
- **THEN** 返回 403，无数据写入
