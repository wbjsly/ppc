# Spec Delta: tax-policy-register

## Purpose
税码政策台账（1.6.2）：税收政策文件的登记与唯一性、政策文号锁定与被引用禁删、按政策维度回链查看其触发的税码变更记录，落实 S-4.1-07 合规更新场景的政策侧留痕。

## ADDED Requirements

### Requirement: 政策登记与必填校验
系统 MUST 支持登记税收政策文件：政策文号（必填、全局唯一、2~64 位）、政策名称（必填，≤128 字）、发文机关（必填，≤64 字）、发布日期、生效日期（均必填，生效日期不得早于发布日期）、摘要（≤500 字，可空）、备注（可空）。重复政策文号 MUST 阻断并提示已存在（409 或 422 口径统一为 409 语义：资源冲突）。登记与编辑 MUST 记录操作人与时间（审计留痕 L5）。

#### Scenario: 政策文号唯一
- **WHEN** 登记已存在的政策文号 `税总公告2026年第15号`
- **THEN** 系统阻断并提示该政策文号已登记

#### Scenario: 生效日期不得早于发布日期
- **WHEN** 发布日期 2026-09-01、生效日期 2026-08-01
- **THEN** 系统 422 阻断并提示生效日期不得早于发布日期

### Requirement: 政策文号锁定与被引用禁删
政策文号 MUST 登记后不可修改（422 提示）；政策被任一税码记录的政策文号引用时 MUST 阻断删除（422 并返回引用计数），未被引用的政策 MUST 可硬删（政策台账无区间/历史语义，删除仅记录操作日志）；生效中政策的编辑（摘要/备注除外的关键字段）MUST 保留变更记录。

#### Scenario: 被引用政策禁删
- **WHEN** 删除的政策文号已被 3 条税码记录引用
- **THEN** 系统 422 阻断并提示「被 3 条税码记录引用，不可删除」

#### Scenario: 未引用政策可删
- **WHEN** 删除无任何税码引用的政策
- **THEN** 删除成功，列表不再展示

### Requirement: 关联税码变更回链
系统 MUST 提供按政策的关联查询：返回该政策文号关联的全部税码记录（税码编号、税率值、区间、计算态）及其版本变更流水（版本号、操作类型、差异摘要、变更原因、时间），按时间倒序。无关联记录 MUST 返回空列表并明示「该政策暂无关联税码变更」（非空结构含提示语）。

#### Scenario: 政策维度看变更
- **WHEN** 打开政策 `税总公告2026年第15号` 的关联抽屉
- **THEN** 展示引用该文号的税码清单与各自版本流，倒序排列

#### Scenario: 无关联明示
- **WHEN** 查询尚未被引用的政策
- **THEN** 返回空清单与提示语，不报错

### Requirement: 权限
政策登记、编辑、删除 MUST 要求 ROLE_ADMIN（403）；列表与关联查询须已认证（401）；页面挂载于菜单 1.6.2（`/m/1.6.2`，M1-6-2 已注册）。

#### Scenario: 普通用户只读
- **WHEN** ROLE_USER 尝试登记政策
- **THEN** 返回 403，无数据写入
