# Spec Delta: tax-code-maintenance

## Purpose
税码主数据维护（1.6.1）：以税码编号为序列键的生效区间模型、必填与枚举校验、区间不重叠不断档硬阻断、历史 append-only、按日期试算预铺 4.14 计税、版本快照与 MDM.TAXCODE 变更事件。

## ADDED Requirements

### Requirement: 税码记录创建与字段校验
系统 MUST 支持创建税码记录，字段含：税码编号（大写字母数字与短横线，2~32 位）、税率值（>0 且 ≤100，4 位小数精度）、生效日期、失效日期（不得早于生效日期）、适用范围（DOMESTIC 国内 / EXPORT 出口 / EXEMPT 免税 三选一）、政策文号（必填，C-4.1-04）、计税方式（GENERAL 一般 / SIMPLIFIED 简易 / DIFFERENTIAL 差额，缺省 GENERAL）、税率类型（STANDARD 标准 / LOW 低税率 / ZERO 零税率 / EXEMPT 免税，缺省 STANDARD）。任一必填缺失或枚举/格式非法 MUST 以 L1 硬阻断拒绝保存（BR-4.1-16）；税率值 0 仅允许在 税率类型=ZERO 或 EXEMPT 时（否则 422 提示与税率类型矛盾）。创建 MUST 生成版本快照（CREATE）并写入 `MDM.TAXCODE.CREATED` outbox 事件，幂等键 = `税码编号:生效日期:{记录ID前8位}:vN`（含记录身份：同记录同版本重放被唯一索引拒绝，软删后同税码同日期重建不撞键——修正汇率域实测踩中的缺陷）。

#### Scenario: 必填缺失阻断
- **WHEN** 提交缺少政策文号或生效日期的税码记录
- **THEN** 系统 L1 阻断并逐项提示缺失字段

#### Scenario: 枚举与精度
- **WHEN** 提交计税方式为 `XXX` 或税率值 13.00001
- **THEN** 系统阻断：枚举须为三选一，税率按 4 位小数四舍五入校验

#### Scenario: 税率值与税率类型矛盾
- **WHEN** 税率值=0 且税率类型=STANDARD
- **THEN** 系统 422 阻断并提示零税率须标记税率类型为零税率或免税

### Requirement: 按税码序列的区间冲突与断档阻断
区间校验 MUST 按「税码编号」独立序列执行（BR-4.1-17 字面口径）：新记录闭区间 [生效日, 失效日] 与同税码既有区间相交 MUST 阻断并返回冲突区间清单；存在断档（新记录生效日 > 上一条衔接记录失效日 + 1 天）MUST 阻断并给出可操作口径（衔接日期）。同税码无既有记录 MUST 放行（首条）；编辑时 MUST 排除自身区间。贴合链首/链尾（共享端点）MUST 放行。

#### Scenario: 区间相交阻断
- **WHEN** 税码 VAT-13 已有 [2026-01-01, 2026-06-30]，新提交 [2026-06-01, 2026-12-31]
- **THEN** 系统阻断并返回冲突区间 [2026-01-01, 2026-06-30]

#### Scenario: 断档阻断
- **WHEN** 同税码上一条失效日为 2026-06-30，新提交生效日为 2026-07-02
- **THEN** 系统阻断并提示新记录生效日须 ≤ 2026-07-01

#### Scenario: 首条与贴合放行
- **WHEN** 税码首次录入，或新段生效日恰为既有链最晚失效日 +1
- **THEN** 保存成功

### Requirement: 税码编号锁定与历史不可篡改
税码编号 MUST 创建后不可修改（C-4.1-01，变更提交含异号编号 422 提示走新建+停用）；生效日期已过期（失效日 < 今天）的记录 MUST 拒绝编辑与删除（BR-4.1-18，422）；生效中/未生效记录变更 MUST 要求变更原因（≥2 字，入版本快照 UPDATE）并重跑区间校验；并发变更以乐观锁判定（verNo 不匹配 409）。

#### Scenario: 编号改号被拒
- **WHEN** 对既有记录提交不同的税码编号
- **THEN** 系统 422 阻断并提示编号创建后不可修改

#### Scenario: 编辑历史被拒
- **WHEN** 对失效日期早于今天的记录提交变更
- **THEN** 系统 422 拒绝并提示历史区间不可篡改

### Requirement: 按日期试算查询（4.14 预铺）
系统 MUST 提供按（税码编号、日期）的试算查询：返回目标日期落在生效区间内的记录（税率值、税率类型、计税方式、适用范围、区间、政策文号）；无命中 MUST 明示「该日期无有效税码」并列出排查原因（该税码无记录 / 日期不在任何区间内），MUST NOT 返回空对象——为 4.14 计税（C-4.14-01 税率缺失或过期阻断）与 BR-4.14-10 按业务发生日取税率提供数据口径。

#### Scenario: 区间内命中
- **WHEN** 查询 VAT-13 在 2026-10-03 的税率，存在覆盖区间
- **THEN** 返回税率值、税率类型、计税方式与政策文号

#### Scenario: 缺失明示
- **WHEN** 查询日期不在任何生效区间内
- **THEN** 返回非空结构：「该日期无有效税码」+ 排查原因列表

### Requirement: 列表与生命周期展示
列表 MUST 支持按税码编号关键字、适用范围、计税方式、计算态筛选与分页；每条记录 MUST 按日期计算展示 未生效/生效中/已失效 三计算态标签（不落状态列）；已失效记录 MUST 不提供编辑与删除入口。

#### Scenario: 计算态筛选
- **WHEN** 列表同时存在三类记录，筛选「生效中」
- **THEN** 仅返回当前区间覆盖今天的记录

### Requirement: 权限、版本与事件
税码创建、变更、删除 MUST 要求 ROLE_ADMIN（403）；列表、详情、试算须已认证（401）。全部写操作 MUST 生成版本快照（含前后值与原因），`MDM.TAXCODE.CREATED/UPDATED` 事件写入 outbox（状态 PENDING 桩口径）；同税码同生效日期的同版本重复发布 MUST 被幂等键唯一索引拒绝（409）。提供既有 versions/diff 同款版本查询与两版本对比接口。

#### Scenario: 非管理员录入
- **WHEN** ROLE_USER 提交创建税码
- **THEN** 返回 403，无数据写入

#### Scenario: 事件可筛
- **WHEN** 税码变更成功后按 `MDM.TAXCODE.UPDATED` 筛选事件流
- **THEN** 命中该事件，幂等键为 `税码编号:生效日期:{记录ID前8位}:vN`
