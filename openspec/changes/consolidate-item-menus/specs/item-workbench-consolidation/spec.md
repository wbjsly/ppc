# Spec Delta: item-workbench-consolidation

## Purpose
物料管理四个三级菜单（新建/变更/停用/替代）整合为单一物料管理列表页：一个入口承载物料全生命周期动作（新建、行内变更、停用/启用/归档、替代维护、影响分析），菜单编号重排且旧路径兼容重定向。

## ADDED Requirements

### Requirement: 单一物料管理入口
系统 MUST 将物料新建、物料变更、物料停用、替代物料四个菜单功能整合到一个「物料管理」菜单（1.2.1，`/m/1.2.1`）下的单列表页。物料分类维护 MUST 保留为独立菜单并改号为 1.2.2（`/m/1.2.2`）。原四功能的全部既有行为（编码生成、查重、477 替代三校验、停用阻断、启用回退、归档终态、替代正反查）MUST 无损保留。

#### Scenario: 菜单整合后入口
- **WHEN** 用户打开基础数据-物料管理菜单
- **THEN** 仅显示「物料管理」（1.2.1）与「分类维护」（1.2.2）两个三级菜单，原 1.2.2/1.2.4/1.2.5 菜单项不再出现

#### Scenario: 全功能单页可达
- **WHEN** 用户进入物料管理页
- **THEN** 从该页可完成：新建、行内变更、单条停用、批量停用、启用、归档、设置/清除替代、影响分析查看，无需跳转其它页面

### Requirement: 单列表筛选与动作装配
单列表 MUST 提供组合筛选：关键字、状态（启用/停用/已归档）、是否配置替代、替代维度（正向/反查）。列表 MUST 展示替代指向列（失效指向红标）。行操作 MUST 按物料状态可用：启用行可变更/停用，停用行可变更/启用/归档，归档行为终态仅可查看；替代设置/清除与影响分析 MUST 对相应状态行可用。批量停用 MUST 保留于工具栏且仅启用态行可勾选。

#### Scenario: 状态筛选联动动作
- **WHEN** 用户筛选状态=已归档
- **THEN** 列表仅显示归档物料，行操作不含停用/启用/归档按钮，展示终态标识

#### Scenario: 替代维度切换
- **WHEN** 用户将替代维度切换为「反查」并输入关键字
- **THEN** 列表仅显示替代指向命中关键字的物料（谁指向我），与原 1.2.5 反查语义一致

### Requirement: 菜单编号重排与种子同步
菜单调整 MUST 通过修订 `docs/design/08-erp-menu.md` 并重新生成 `099-menu-seed.sql` 实现（禁止手工编辑种子）；存量数据库 MUST 通过新增幂等迁移脚本修正 `erp_admin_menu` 行：删除原 1.2.2/1.2.4/1.2.5 行、将原 1.2.1 更新为整合菜单、将原 1.2.3 更新为 1.2.2（或按迁移幂等设计执行），迁移重复执行 MUST 不产生重复或脏数据。

#### Scenario: 存量库菜单修正
- **WHEN** 后端启动执行新迁移脚本
- **THEN** `erp_admin_menu` 中 1.2 子树为两行（1.2.1 物料管理、1.2.2 分类维护），重复重启不改变结果

#### Scenario: 全新安装
- **WHEN** 全新数据库按序执行全部迁移（含重生成后的 099）
- **THEN** 菜单结果与存量库修正后一致

### Requirement: 旧路由兼容
原 `/m/1.2.4`、`/m/1.2.5` 路径 MUST 重定向至 `/m/1.2.1`，访问 MUST NOT 出现 404 或占位页。新 `/m/1.2.2` MUST 指向分类维护；由于旧「物料变更」与新「分类维护」路径相同，旧 `/m/1.2.2` 书签将呈现分类维护页（路径冲突无法双重兼容，作为已知取舍记录，变更动作在物料管理页内可达）。

#### Scenario: 旧链接重定向
- **WHEN** 用户访问 `/m/1.2.4` 或 `/m/1.2.5`
- **THEN** 页面重定向到 `/m/1.2.1` 物料管理页并正常渲染

#### Scenario: 分类维护新路径
- **WHEN** 用户访问 `/m/1.2.2`
- **THEN** 渲染分类维护页面

#### Scenario: 旧变更路径呈现新语义
- **WHEN** 用户访问 `/m/1.2.2`（原物料变更书签）
- **THEN** 呈现分类维护页，不报错；物料变更动作可在物料管理页行内完成

### Requirement: 回归无损
整合后 MUST 通过既有五个流程的回归验证：物料新建（自动编码+查重）、物料变更（关键属性判定+快照）、停用工作台动作（原因必填、409/422 阻断回显）、替代维护（正反查+三校验）、分类维护（改号后入口与功能不变）。console MUST 无 error/warn。

#### Scenario: 新建流程回归
- **WHEN** 在整合页点击新建并提交合法物料
- **THEN** 生成三段式编码并创建成功，列表即时刷新

#### Scenario: 阻断回显回归
- **WHEN** 在整合页对被替代引用的物料提交停用
- **THEN** 弹出 409 阻断提示并列出引用方清单，状态不变
