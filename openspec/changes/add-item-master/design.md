# Design

## Context

首个非组织类主数据，也是首个**带外部参照依赖**的模块。与前五轮差异：编码不是简单流水（三段式）、表单有分类差异化字段、参照数据（分类/字典）需先落地。动机与偏差见 proposal.md。约束同前：JDK 17 + Spring Boot 2.7.18 + MyBatis-Plus、`erp_mdm_` 表前缀、`DbBootstrap` 迁移、写接口 ROLE_ADMIN、版本快照记变更后新值。

## Goals / Non-Goals

- Goals：分类种子表 + 物料两表 + 三段式编码 + 流程一第 1/2/4 步校验与发布 + 详情基础变更/停用
- Non-Goals：1.2.2/1.2.3/1.2.4/1.2.5 独立菜单能力、审批、Pending 生效、事件总线、归档、动态属性集、多工厂视图（见 proposal 偏差表）

## Decisions

**1. 分类表 `erp_mdm_item_category` 承载编码规则**：字段 `CATEGORY_CODE`（4 位分类码）、`ITEM_PREFIX`（FG/RM/WIP）、`PARENT_ID`（树形预留，本期只种三大类 + 示例二级）、`LEVEL`。
- 三大类种子即编码规则的权威来源，1.2.3 后续做管理界面时表结构已就位（只加 CRUD 不改结构）。
- 备选：分类写死在 Java 枚举 → 拒绝，分类码是数据属性（未来可增），枚举改动需发版。
- 编码 = `ITEM_PREFIX + CATEGORY_CODE + 6位流水`（如 `RM` + `0001` + `000001` = `RM0001000001`，共 12 位），流水在**叶子分类内** `MAX(ITEM_CODE)` 独立计数。

**2. 手输编码校验策略**：既校验「前缀与所选分类一致」（BR-4.1-07 L1），也做唯一性 + 查重提示近 3 条；自动编码走唯一索引冲突重试 3 次（沿既有模式，前缀长度按 `prefixLen = itemPrefix.length() + 4` 计算 —— 分类码恒 4 位，无成本中心那次 `substring` 偏移风险，但仍在代码注释标明长度构成）。

**3. 字典 = 后端常量枚举 + 分类表查询接口**，不建字典表：
- 采购类型 `PURCHASE_TYPE`：`BUY/MAKE/OUTSOURCE`；存储条件 `STORAGE`：`NORMAL/CHILL/FROZEN/HAZARD`；单位与物料组是开放集合 → 存**种子表**更合适？
- 决策：单位/物料组数量有限且本轮只读 → 建 `erp_mdm_item_dict`（`DICT_TYPE` + `DICT_CODE` + `DICT_NAME`），一表承载单位/物料组/存储条件，**采购类型用枚举**（它是表单核心业务字段且规格明文三项）。这样开放集合（单位/物料组）可加种子行而不发版，与 1.2.3 字典管理未来兼容。
- 备选：全部枚举 → 单位新增需发版；全部字典表 → 采购类型过度配置化。

**4. 简化属性集 = 表单条件渲染 + 物理列**：`SHELF_LIFE_DAYS`（原材料）、`PACKING_SPEC`/`BARCODE`（成品）直接做列，前端按分类前缀显示/隐藏对应字段组，后端按分类校验（原材料批次管理时保质期必填）。
- 备选：EAV 属性表/JSON 列 → 拒绝，三类固定字段用物理列最简单可查，规格「属性集模板」动态化留给 1.2.3。

**5. 分类接口**：`GET /api/mdm/item-categories`（全部叶子+父级），表单与筛选共用；分类变更影响编码规则 → 本轮无分类管理界面，种子即终态。

**6. 查重编辑距离 ≤3**：服务端实现朴素 Levenshtein（≤3 规模数据下 O(n·m) 足够），名称+规格型号组合键；前端「确认非重复 + 差异说明」在提交体携带 `forceCreate=true`/`dupNote` 两个可选字段绕过相似度阻断（不绕过唯一性阻断）。

## Risks / Trade-offs

- 分类种子值若与真实业务不符，改种子需清 marker 重跑或手工 UPDATE → 种子标注示例、投产前替换（沿既有惯例）
- 12 位编码长度校验（手输）：格式正则 `^(FG|RM|WIP)\d{4}\d{6}$`（分类码部分再与所选分类比对）
- 单位换算（主辅单位）规格提及但无细则 → Non-Goal，字段仅存基本单位 + 辅助单位编码占位

## Migration Plan

`015`（分类+字典种子）→ `016`（物料两表 + 示例物料），marker 顺序执行；回滚删表。两脚本幂等（IF NOT EXISTS + INSERT IGNORE）。
