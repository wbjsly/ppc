# Spec Delta

## Purpose
物料新建全链路（菜单 1.2.1）：带三段式编码与查重校验的物料主数据创建、立即发布与版本追溯，以及分类/字典参照数据源。

## ADDED Requirements

### Requirement: 物料分类与字典数据源
系统 SHALL 提供物料分类参照数据（三大类种子：成品 FG、原材料 RM、半成品 WIP，各类含 4 位分类码与名称）及计量单位、采购类型（外购/自制/委外）、存储条件、物料组的固定枚举数据源，供物料表单下拉选择与校验。

#### Scenario: 表单获取分类与字典
- **WHEN** 用户打开物料新建表单
- **THEN** 分类、基本计量单位、物料组、采购类型、存储条件下拉均返回有效选项（分类含三大类，采购类型恰为三项）

#### Scenario: 无效参照被阻断
- **WHEN** 提交的物料组或计量单位不在既定清单内
- **THEN** 系统拒绝保存并提示参照数据无效

### Requirement: 三段式物料编码
系统 SHALL 按 `{FG|RM|WIP} + 4位分类码 + 6位流水` 生成物料编码（按分类独立流水、全局唯一），支持系统自动编码与手工输入双模式；手工输入 MUST 校验前缀与所选分类一致，不一致时以 L1 硬阻断并展示最近 3 条相似编码（BR-4.1-07 / C-4.1-01 / C-4.1-07）；编码创建后 MUST 不可修改（BR-4.1-13）。

#### Scenario: 自动编码生成
- **WHEN** 用户选择分类「原材料（RM0001）」且编码留空提交
- **THEN** 系统生成 `RM0001` + 6 位流水（如 `RM0001000001`），同分类下次生成流水递增

#### Scenario: 手输编码前缀不一致被阻断
- **WHEN** 用户选择成品分类但手工输入 `RM0001000001`
- **THEN** 系统 L1 阻断并标红编码字段，展示最近 3 条相似编码

#### Scenario: 尝试修改编码
- **WHEN** 变更请求包含对物料编码的修改
- **THEN** 系统阻断并提示编码创建后不可修改

### Requirement: 物料新建表单与校验
系统 SHALL 提供物料新建表单，必填：编码（或自动生成）、名称、分类、基本计量单位、物料组、采购类型、存储条件；选填：替代物料编码、安全库存量、采购提前期、批次管理标识；并按分类加载差异化字段（原材料 → 保质期天数；成品 → 包装规格、条码）。提交时 MUST 执行：必填校验、名称+规格查重（编辑距离 ≤3 时展示最近 3 条，用户可勾选「确认非重复」并填写差异说明）、批次管理物料保质期必填（BR-4.1-08）、名称特殊字符 `<>&` 过滤（BR-4.1-10）。

#### Scenario: 必填缺失被阻断
- **WHEN** 用户未填写物料名称与采购类型即提交
- **THEN** 系统拒绝保存并高亮定位缺失字段

#### Scenario: 名称相似提示并可确认非重复
- **WHEN** 输入的名称与既有物料「不锈钢管 DN50 304L」编辑距离 ≤3
- **THEN** 系统展示最近 3 条相似记录；用户勾选「确认非重复」并填写差异说明后可继续提交

#### Scenario: 批次管理缺保质期被阻断
- **WHEN** 用户勾选批次管理标识但保质期天数为空
- **THEN** 系统阻断提交并高亮保质期字段（BR-4.1-08）

#### Scenario: 自制件 BOM 后补提示
- **WHEN** 采购类型选「自制」且未填 BOM 版本号
- **THEN** 系统允许提交并提示 BOM 待补录（L4，BR-4.1-09）

### Requirement: 立即发布与版本快照
物料保存成功 SHALL 立即生效（状态 Active、版本 V1）；每次变更 MUST 生成递增版本快照（变更后新值 + 差异摘要）并以 `verNo` 乐观锁防并发覆盖。

#### Scenario: 新建成功生成 V1
- **WHEN** 用户完成表单并提交成功
- **THEN** 物料状态为 Active，版本表存在 V1 CREATE 快照

#### Scenario: 并发编辑冲突
- **WHEN** 后提交者 `verNo` 已不匹配
- **THEN** 系统阻断并提示刷新后重试，库中保留先提交者数据

### Requirement: 物料列表、详情与变更
系统 SHALL 提供物料分页列表（关键字/分类/状态筛选）与详情视图；变更 SHALL 限非编码字段，变更后立即生效并入版本历史。

#### Scenario: 按分类与状态筛选
- **WHEN** 用户选择分类「成品」且状态「启用」
- **THEN** 仅返回该分类下 Active 物料

#### Scenario: 变更生成新版本
- **WHEN** 用户修改安全库存量并保存
- **THEN** verNo 加 1，版本表新增 V(N+1) 快照且 diffSummary 记录字段差异

### Requirement: 物料停用与硬删禁止
系统 SHALL 支持物料停用（软删除，历史单据引用仍可展示）；MUST 禁止物理删除（C-4.1-03）；被下游业务数据引用时停用 MUST 被阻断并列出引用清单。

#### Scenario: 无引用时停用成功
- **WHEN** 用户对无下游引用的物料执行停用并确认
- **THEN** 状态变为 Inactive，仍可查询，版本表新增停用快照

#### Scenario: 物理删除请求被拒绝
- **WHEN** 任意客户端发起物理删除请求
- **THEN** 系统拒绝，仅允许停用

### Requirement: 访问权限控制
物料增删改查接口 MUST 要求有效 JWT；写操作 MUST 限定 ROLE_ADMIN，未授权返回 403、未认证返回 401。

#### Scenario: 普通用户尝试新建
- **WHEN** ROLE_USER 用户调用新建接口
- **THEN** 返回 403 且不产生数据

#### Scenario: 未认证请求
- **WHEN** 未携带 JWT 调用列表接口
- **THEN** 返回 401
