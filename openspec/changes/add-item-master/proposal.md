# Proposal

## Why

菜单 1.2.1「物料新建」指向占位页。物料是采购（4.2）、库存（4.4）、生产 BOM/MRP（4.5）、销售（4.3）全链路的引用基础，规格流程一（FR-4.1-1-1~6）是 4.1 MDM 域第一个全流程。规格对编码规则（BR-4.1-07：`FG/RM/WIP + 4位分类码 + 6位流水`）有明文，但**三个外部依赖在系统中均不存在**：物料分类树（菜单 1.2.3 未建）、计量单位字典、物料组 —— 经需求沟通（2026-10-01）确定解法：**种子分类表 + 种子/固定枚举字典**，使编码规则可完整落地且不预占 1.2.3 范围。

## What Changes

- **种子分类表** `erp_mdm_item_category`（迁移 `015`）：三大类种子（成品 FG / 原材料 RM / 半成品 WIP，各含 4 位分类码）+ 二级示例分类；**不做 1.2.3 分类管理界面**，表与数据先行
- **物料本体** `erp_mdm_item` + `erp_mdm_item_version`（迁移 `016`）：**全量字段** —— 必填 7（编码、名称、分类、基本单位、物料组、采购类型、存储条件）+ 选填 4（替代物料编码、安全库存量、采购提前期、批次管理标识）+ 分类差异化字段（原材料：保质期天数；成品：包装规格、条码）
- **编码规则对齐 BR-4.1-07**：`{FG|RM|WIP}` + 4 位分类码 + 6 位流水（按分类独立计数、全局唯一）；自动/手输双模式，手输校验前缀与所选分类一致 → L1 阻断 + 近 3 条相似提示；编码创建后不可改
- **校验对齐流程一第 2 步**：唯一性（C-4.1-01）、名称+规格查重（编辑距离 ≤3，近 3 条 +「确认非重复」+差异说明，C-4.1-07）、参照完整性（分类/单位/物料组存在）、批次管理必填保质期（BR-4.1-08）、自制件 BOM 后补 L4 提示（BR-4.1-09）、名称特殊字符过滤（BR-4.1-10）
- **字典来源**：计量单位 / 采购类型（外购/自制/委外）/ 存储条件 / 物料组 —— 后端固定枚举与种子，无字典管理页
- **简化属性集**：按三大类固定字段组（原材料显示保质期，成品显示包装规格/条码），不做动态属性集模板
- 详情内提供**基础版变更与停用**（版本快照 V1 起、乐观锁、停用软删 + 下游引用桩），不预占 1.2.2/1.2.4 菜单能力
- 前端 `views/mdm/item/`，菜单 `M1-2-1`（`/m/1.2.1`）切真实页；`SecurityConfig` 写接口 ADMIN

### 与规格的已知偏差（需求沟通确认，2026-10-01）

| 规格条目 | 规格要求 | 本轮决策 |
|---|---|---|
| FR-4.1-1-3 审批 | 双人复核（部门审核 + 主数据管理员终审）、超时升级 | **无审批，保存立即生效**（沿前四轮基线） |
| FR-4.1-1-4 发布 | 未来生效日期 → `Pending` 状态 | **不做**；立即 `Active`（版本快照保留） |
| FR-4.1-1-4/1-5 事件 | `MDM.ITEM.PUBLISHED` 发布-订阅、重试 3 次、运维工单 | **留桩**（无事件总线，标记 TODO） |
| FR-4.1-1-6 归档 | 迁移归档库、仅管理员、归档原因 | **Non-Goal** |
| 属性集模板 | 分类选择时动态加载属性集 | **简化为三大类固定字段组** |
| S-4.1-08 多工厂视图 | 工厂扩展 MRP 参数/采购类型/存储地点 | **Non-Goal**（待工厂场景真实需求） |
| BR-4.1-20/21、C-4.1-09 | 分类树重构/切换窗口挂起 | 属 1.2.3，**Non-Goal** |
| 停用引用分析 | 活跃 PO/SO/BOM 引用 L1 阻断 | **校验桩**（下游未建，标 TODO 回补） |

**已对齐的规格约束**：C-4.1-01 编码唯一不可改、C-4.1-07 近 3 条相似提示、BR-4.1-07 编码前缀与分类一致、BR-4.1-08 批次必填保质期、BR-4.1-09/10、C-4.1-03 禁硬删、C-4.1-05 乐观锁、C-4.1-06 版本快照、DC-02 参照完整性。

## Impact

- Affected specs: `item-master-creation`（新增）
- Affected code:
  - 迁移 `015-mdm-item-category.sql`（分类种子）、`016-mdm-item.sql`（物料两表 + 示例物料）

- 复用：版本快照/乐观锁/停用桩模式（前三模块）、菜单种子已有 `M1-2-1` 行
