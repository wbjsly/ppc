# Spec Delta: item-disable-archive

## Purpose
物料停用工作台：停用前影响分析（替代引用硬阻断 + 下游引用桩明示）、单条与批量停用、启用回退、标记式归档与通知单事件桩，保证停用全生命周期可追溯且历史单据引用不受影响。

## ADDED Requirements

### Requirement: 停用前影响分析
系统 MUST 在停用执行前提供影响分析，列出两类引用：①替代引用（真实数据，来自其他物料对该物料的 `ALT_ITEM_CODE` 指向）；②下游业务引用（PO/SO/BOM 等）。下游引用当前为桩实现，接口 MUST 返回空清单并携带「模块未接入」的明示标记，前端 MUST 向用户展示该口径说明，不得伪装为「无引用」以外的确定性结论。

#### Scenario: 存在替代引用时的分析结果
- **WHEN** 对物料 A 请求影响分析，且存在启用中物料 B 的替代指向为 A
- **THEN** 返回引用方清单（B 的编码与名称）与总数，且页面标注为硬阻断项

#### Scenario: 下游桩口径明示
- **WHEN** 请求影响分析，采购/销售/生产模块尚未接入
- **THEN** 下游引用返回空清单且带未接入标记，页面显示「采购/销售/生产模块未接入，暂无数据」说明

### Requirement: 单条停用
停用 MUST 将状态由启用（1）置为停用（0），必填停用原因，使用乐观锁（verNo）防并发，并生成 `DISABLE` 版本快照（记录状态变化与原因）。若物料存在替代引用，系统 MUST 以硬阻断拒绝并列出引用方清单（前 10 条 + 总数）。已处于停用或归档状态的物料 MUST 被拒绝重复停用。停用后物料 MUST NOT 被任何新业务引用（如下拉选项），历史数据中的引用 MUST 保持有效可查。

#### Scenario: 替代引用阻断
- **WHEN** 对正被启用物料 B 作为替代指向的物料 A 提交停用
- **THEN** 返回硬阻断与引用方清单，A 状态保持不变

#### Scenario: 停用成功
- **WHEN** 对无引用的启用物料提交停用并填写原因
- **THEN** 状态变为 0，生成含原因的 DISABLE 快照，且新业务选项列表不再包含该物料

#### Scenario: 重复停用被拒绝
- **WHEN** 对已停用物料再次提交停用
- **THEN** 系统拒绝并提示已处于停用状态

### Requirement: 批量停用
系统 MUST 支持批量停用：逐条执行与单条相同的校验与快照逻辑；单条失败 MUST NOT 阻断其余记录执行，结果 MUST 按成功/失败分别返回（含失败原因），前端 MUST 展示汇总结果。

#### Scenario: 部分失败的批量停用
- **WHEN** 批量停用 3 条物料，其中 1 条存在替代引用
- **THEN** 另外 2 条成功停用并各自生成快照，返回结果标明第 1 条失败及原因

### Requirement: 启用回退
停用的物料 MUST 可被启用（状态 0 → 1），必填启用原因并生成 `ENABLE` 快照。启用时系统 MUST 重跑校验：若该物料的替代指向目标已失效（停用或归档），则阻断启用并提示先清除或改指替代。已归档物料 MUST NOT 直接启用；已启用物料重复启用 MUST 被拒绝。

#### Scenario: 启用成功
- **WHEN** 对替代指向为空或目标有效的停用物料提交启用并填写原因
- **THEN** 状态变为 1，生成 ENABLE 快照，物料重新可被新业务引用

#### Scenario: 替代目标已失效时阻断启用
- **WHEN** 停用物料的替代指向目标当前为停用状态，提交启用
- **THEN** 系统阻断并提示替代目标已失效，状态保持 0

#### Scenario: 已归档物料不可直接启用
- **WHEN** 对状态为归档的物料提交启用
- **THEN** 系统拒绝并提示归档为终态

### Requirement: 标记式归档
仅处于停用状态且无活跃替代引用的物料 MUST 可归档（状态 0 → 2），必填归档原因，仅 ADMIN 权限可执行，并生成 `ARCHIVE` 快照。归档 MUST 为终态：已归档物料 MUST NOT 被新业务引用、MUST NOT 直接启用。规格中的「迁移至归档库」本期降级为状态标记，不执行数据迁移。

#### Scenario: 归档成功
- **WHEN** 对无引用的停用物料提交归档并填写原因
- **THEN** 状态变为 2，生成 ARCHIVE 快照，物料从业务可引用范围排除

#### Scenario: 非停用态归档被拒绝
- **WHEN** 对启用中的物料提交归档
- **THEN** 系统拒绝并要求先停用

### Requirement: 停用通知单事件桩
停用成功后系统 MUST 写入 `MDM.ITEM.DISABLED` 事件日志桩（目标：推送采购、销售、库存部门），事件总线未接入期间 MUST 至少落日志留痕，实现方式与既有 `MDM.ITEM.PUBLISHED` 桩保持一致。

#### Scenario: 停用事件留痕
- **WHEN** 物料停用成功
- **THEN** 系统记录 DISABLED 事件日志（物料编码、原因、操作人、时间）

### Requirement: 权限控制
停用、批量停用、启用、归档等写操作 MUST 要求 ROLE_ADMIN；影响分析与列表查询要求已认证。未认证请求 MUST 返回 401，非管理员写操作 MUST 返回 403。

#### Scenario: 非管理员停用
- **WHEN** ROLE_USER 用户提交停用请求
- **THEN** 返回 403，状态不变
