# Spec Delta: exchange-rate-batch-import

## Purpose
汇率批量更新：零依赖 CSV/粘贴载体与模板下载、复用单条校验组与区间衔接算法的行级预检、按行独立提交的部分失败语义、含成功失败统计与原因明细的导入结果报告。

## ADDED Requirements

### Requirement: 模板下载与两种录入
系统 MUST 提供批量导入模板下载（表头：基础币种/报价币种/汇率类型/生效日期/失效日期/汇率值/来源文件编号），模板 MUST 含格式说明（类型枚举、ISO 4217、区间衔接规则）。录入 MUST 支持两种等价方式：① 上传 `.csv` 文件（UTF-8/BOM 容错、逗号或制表符分隔、自动跳过表头与空行）② 粘贴表格文本（电子表格直接复制的 Tab 分隔文本）。两种方式 MUST 解析为相同的行结构供预检；行内「来源文件编号」为空时 MUST 回填整批公共值（行 552：一次央行公告覆盖多行）。

#### Scenario: CSV 解析
- **WHEN** 上传含 BOM 头与表头行的 CSV（5 数据行）
- **THEN** 解析出 5 行进入预检，表头与空行被跳过，中文无乱码

#### Scenario: 粘贴录入等价
- **WHEN** 从电子表格复制 3 行含 Tab 分隔的数据粘贴
- **THEN** 解析结果与上传同内容 CSV 一致

#### Scenario: 公共来源编号回填
- **WHEN** 行内来源文件编号为空且整批公共值为「央行公告2026-11」
- **THEN** 预检与提交中该行的来源文件编号均为公共值

### Requirement: 行级预检（dry-run）
系统 MUST 提供不落库的预检接口：对每一行复用既有单条校验规则（必填四件、ISO 币种 3 位大写且基础≠报价、汇率 >0 且 6 位精度、失效日期 ≥ 生效日期），并对区间衔接执行与单条一致的校验（BR-4.1-17 传导）：同（币对×类型）的批内行 MUST 先按生效日期排序，逐段与存量区间链及批内前序段衔接判定（相交/断档/左缺口给出可操作口径）。返回 MUST 为逐行结构 `{rowNo, valid, reason, normalized}`，前端据此红绿标展示；预检 MUST NOT 写入任何数据。

#### Scenario: 行级必填缺失标记
- **WHEN** 第 3 行缺来源文件编号且无公共值
- **THEN** 第 3 行 valid=false 且 reason 含「来源文件编号必填」，其余行不受影响

#### Scenario: 批内衔接传导
- **WHEN** 同币对同类型两行批内排序后第二行生效日与第一行失效日断档
- **THEN** 第二行标记断档原因（含应 ≤ 的衔接日期），第一行仍 valid=true

#### Scenario: 与存量链衔接
- **WHEN** 某行生效日晚于同序列存量链尾失效日 + 1 天
- **THEN** 该行标记断档原因并给出允许的最大生效日

### Requirement: 按行独立提交与部分失败
确认提交 MUST 按行独立执行（BR-4.1-19 按行提交）：每行以独立事务调用与单条创建相同的逻辑（含校验、版本快照、`MDM.RATE.CREATED` 事件）；单行失败 MUST 收集其行号与原因，MUST NOT 回滚或阻断已成功行；批次行数超过 500 MUST 整批拒绝（422）。提交前预检已标红的行 MUST 同样按行执行（后端为权威，最终结果以后端为准）。

#### Scenario: 部分失败成功行保留
- **WHEN** 5 行提交，其中第 4 行与存量区间相交
- **THEN** 其余 4 行成功发布（各生成快照与事件），第 4 行返回失败原因，响应含分组结果

#### Scenario: 超批拒绝
- **WHEN** 提交 501 行
- **THEN** 系统 422 整批拒绝，无任何行写入

### Requirement: 导入结果报告
提交响应 MUST 为完整结果报告（BR-4.1-19）：`total/succeeded/failed` 统计 + 逐行明细 `{rowNo, 币对, result, reason}`；前端 MUST 展示统计卡与失败行标红明细，并 MUST 支持将报告下载为 CSV（含 BOM，字段：行号/币对/类型/结果/原因）；成功行数 > 0 时 MUST 提供跳转汇率列表的入口。报告数据 MUST 可由本次响应直接获得（不依赖二次查询）。

#### Scenario: 报告统计与下载
- **WHEN** 提交 4 行其中 1 行失败
- **THEN** 报告显示 total=4/succeeded=3/failed=1，失败行标红含原因，下载 CSV 内容与页面一致

### Requirement: 权限与事件
批量预检与提交 MUST 要求 ROLE_ADMIN（403）；模板下载为前端本地生成不涉及接口。成功行事件 MUST 与单条创建一致（`MDM.RATE.CREATED`，幂等键 `币对:type:生效日期:vN`，事件流可筛，无新事件类型）。

#### Scenario: 非管理员提交
- **WHEN** ROLE_USER 调用批量提交
- **THEN** 返回 403，无数据写入
