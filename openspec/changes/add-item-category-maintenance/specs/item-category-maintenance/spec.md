# Spec Delta

## Purpose
物料分类树的常规维护（编码规则权威的管理入口）与受限轻量重构（合并/迁移），含分类自身版本审计与对存量物料的改挂固化。

## ADDED Requirements

### Requirement: 分类树查询
系统 SHALL 提供物料分类树查询（3 级，含层级号、编码前缀、父节点组织），供物料新建表单与管理页共用；返回结构保持父子层级。

#### Scenario: 树形展示
- **WHEN** 用户打开分类维护页
- **THEN** 返回全部分类节点（三大类根 + 二级子分类），按父子层级组织并显示编码前缀

### Requirement: 分类新建
系统 SHALL 支持新建分类：编码为 4 位分类码（全局唯一）、前缀限 FG/RM/WIP、可指定父节点；MUST 校验层级 ≤3、DC-06 不成环、父节点存在；保存立即生效并生成版本 V1 快照。

#### Scenario: 新建子分类
- **WHEN** 用户在「原材料 RM0001」下新建 4 位码 `0006`、前缀 RM 的子分类
- **THEN** 节点创建成功（LEVEL=2），编码 `0006` 唯一，生成 V1 快照

#### Scenario: 层级超限被阻断
- **WHEN** 用户尝试在第 3 级节点下新建子分类
- **THEN** 系统 L1 阻断并提示层级最多 3 级

### Requirement: 分类变更与规则字段锁定
系统 SHALL 支持变更分类名称、父节点、负责人、备注；`ITEM_PREFIX` 与 `CATEGORY_CODE` MUST 创建后不可修改（L1 阻断，防止存量物料编码前缀校验漂移）；变更必填变更原因并入版本快照（V(N+1)、乐观锁）；变更父节点 MUST 通过成环与深度校验。

#### Scenario: 修改编码前缀被阻断
- **WHEN** 用户尝试将 RM0001 的前缀从 RM 改为 FG
- **THEN** 系统 L1 阻断并提示编码规则字段创建后不可修改

#### Scenario: 改父节点通过校验
- **WHEN** 用户将二级分类改挂另一同前缀根节点，层级不超 3 级
- **THEN** 保存成功并生成 V(N+1) 快照，diff 记录 parentId/treeLevel 变化

### Requirement: 分类停用与双重阻断
系统 SHALL 支持分类停用（软删除，禁止物理删除）；停用时 MUST 双重校验：存在启用子孙节点 → 阻断并列出；被启用物料引用 → 阻断并列出物料编码清单。

#### Scenario: 有启用子孙时停用被阻断
- **WHEN** 用户停用「原材料 RM0001」且其下存在启用子分类
- **THEN** 系统阻断并列出全部未停用子孙

#### Scenario: 被启用物料引用时停用被阻断
- **WHEN** 用户停用的分类仍被启用状态物料的 `CATEGORY_CODE` 引用
- **THEN** 系统阻断并列出引用该分类的物料编码（最多展示 10 条）

### Requirement: 分类合并（受限）
系统 SHALL 支持将源分类合并至目标分类，MUST 满足：源与目标 `ITEM_PREFIX` 相同（不同则 L1 阻断）；源分类的子分类改挂目标；存量物料 `CATEGORY_CODE` 批量改挂目标并**逐条生成物料版本快照**（diff 摘记「categoryCode: 旧 → 新（分类合并）」）；源分类自动停用；全程同一事务，任一失败整体回滚；操作原因必填。

#### Scenario: 合并前置影响提示
- **WHEN** 用户对 RM0002 发起合并至 RM0001
- **THEN** 系统展示影响提示（受影响物料 N 个、子分类 M 个），用户确认并填写原因后执行

#### Scenario: 跨前缀合并被阻断
- **WHEN** 用户尝试将 RM0001 合并至 FG0001
- **THEN** 系统 L1 阻断并提示仅允许同一编码前缀的分类合并

#### Scenario: 合并执行结果
- **WHEN** 合并执行成功
- **THEN** RM0002 下子分类与全部存量物料改挂 RM0001、每条物料版本表新增快照、RM0002 状态变为停用，分类版本表新增合并记录（含原因）

### Requirement: 分类迁移
系统 SHALL 支持将分类节点改挂至新的父节点（层级重组）；存量物料与物料编码 MUST 不受影响；迁移必填原因并写入分类版本快照（记录 parentId/treeLevel 变更）；MUST 通过成环与深度校验。

#### Scenario: 迁移节点
- **WHEN** 用户将 RM0002 从 RM0001 下改挂至另一 RM 前缀根节点并填写原因
- **THEN** 节点层级更新，存量物料分类字段不变，分类版本表新增迁移记录

### Requirement: 访问权限控制
分类的写接口（新建/变更/停用/合并/迁移）MUST 要求有效 JWT 且限定 ROLE_ADMIN；查询接口认证即可；未授权 403、未认证 401。

#### Scenario: 普通用户尝试合并
- **WHEN** ROLE_USER 调用合并接口
- **THEN** 403 且数据无变化
