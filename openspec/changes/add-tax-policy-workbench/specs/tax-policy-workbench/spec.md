# Spec Delta: tax-policy-workbench

## Purpose
政策版本快照与 MDM.POLICY 变更事件、政策页版本对比、政策驱动的税码批量切换工作台（候选查询、五类执行计划预检、行级提交与结果报告、切换日≥今天与历史保护），落实 S-4.1-07 执行闭环与主数据版本快照基线。

## ADDED Requirements

### Requirement: 政策版本快照与变更事件
政策登记 MUST 生成 CREATE 版本快照、编辑 MUST 生成 UPDATE 版本快照（含七字段前后值差异摘要 DIFF_SUMMARY；政策无必填变更原因，CHANGE_REASON 置空）；同步写入 outbox `MDM.POLICY.CREATED/UPDATED` 事件，幂等键 = `政策文号:{政策ID前8位}:vN`（N 为快照版本号，同记录同版本重复发布 MUST 被唯一索引拒绝 409）。存量政策（本能力上线前登记）MUST NOT 回填快照——首个快照由上线后首次登记/编辑生成，版本号自 1 起连续。

#### Scenario: 登记生成 CREATE 快照与事件
- **WHEN** 新登记一份政策
- **THEN** 生成 V1 CREATE 快照并产生 `MDM.POLICY.CREATED` 事件（幂等键含政策文号与 ID 前 8 位）

#### Scenario: 编辑生成 UPDATE 快照含差异
- **WHEN** 修改政策的摘要字段
- **THEN** 生成 V2 UPDATE 快照，DIFF_SUMMARY 含 `summary: 旧 → 新`，并产生 `MDM.POLICY.UPDATED` 事件

#### Scenario: 同版本重放拒绝
- **WHEN** 同一政策同版本事件重复发布（幂等键冲突）
- **THEN** 系统 409 拒绝且主操作回滚

### Requirement: 政策版本查询与页内对比
系统 MUST 提供政策版本列表与两版本对比接口：版本列表返回版本号、操作类型、差异摘要、操作人、时间（升序）；对比返回两版本间**全部变更字段**的 `{field, from, to}` 清单（未变字段 MUST NOT 出现）。政策页 MUST 提供「对比」入口：选择 from/to 版本（同版本禁用），逐字段并排展示，旧值红底、新值绿底。

#### Scenario: 逐字段红绿对比
- **WHEN** 对比 V1→V2 仅摘要变化
- **THEN** 差异清单只含 summary 一行，V1 值红底、V2 值绿底

#### Scenario: 同版本禁用
- **WHEN** from 与 to 选择同一版本
- **THEN** 前者/后者选项禁用且对比按钮不可点

### Requirement: 受影响税码候选查询
工作台 MUST 提供按政策的候选税码查询：返回全部非软删税码（按税码编号分组展示其链尾段信息），每项含 税码编号、计算态、链尾生效/失效日、**建议新段生效日 = 链尾失效日 + 1**；支持税码编号/关键字筛选；无候选 MUST 返回空列表明示（非空结构）。已失效税码 MUST 也出现在候选中并标注计算态（是否可切换由预检按计划类型判定）。

#### Scenario: 候选含链尾与建议日期
- **WHEN** 查询候选且存在税码链尾失效日 2026-12-31
- **THEN** 该项建议新段生效日为 2027-01-01，计算态标注生效中

#### Scenario: 空候选明示
- **WHEN** 库中无任何税码
- **THEN** 返回空列表与提示语，不报错

### Requirement: 切换预检与执行计划
工作台预检 MUST 逐行（不落库）为每个勾选税码生成执行计划并给出通过/失败原因，计划类型 MUST 覆盖：
1. 该税码无任何区间 → **新建首段**；
2. 切换日 = 链尾失效日 + 1 → **新建衔接段**；
3. 切换日落在**未失效尾段**内部 → **缩短尾段至切换日-1 + 新建段**（新段失效日取行内指定值）；
4. 切换日落在**中间未失效段**（其后已有后续段）→ **缩短该段 + 新建段，且新段失效日 MUST 自动取后续段生效日-1**（行内失效日被忽略并回显实际值）；
5. 切换日恰为**断档空洞起点**（前段失效日+1 且存在后续段）→ **补洞新建段**（失效日自动=后续段生效日-1）——既覆盖类型 4 提交 PARTIAL 后的重试降级，也覆盖删除中间段遗留空洞从起点切入的补录；
6. 其他情形 MUST 失败并给出可操作口径：切换日早于今天、落入已失效历史区间、早于链首、落在断档空洞内部（非空洞起点）、切换日恰为某段生效日（提示直接在税码维护变更该段）。
预检 MUST 同步执行字段校验（新税率满足税码字段规则含零税率矛盾、新段失效日 ≥ 切换日）与 `IntervalRules` 区间判定；返回逐行 `{rowNo, valid, reason, plan:[{action, summary}]}`（失败行 plan 为空）。

#### Scenario: 尾段内部切换
- **WHEN** 链尾段 [2026-01-01, 2026-12-31] 生效中，切换日 2026-11-01、新段失效日 2027-12-31
- **THEN** 计划为两步：缩短尾段至 [2026-01-01, 2026-10-31] + 新建 [2026-11-01, 2027-12-31]

#### Scenario: 切换日早于今天阻断
- **WHEN** 切换日 = 昨天
- **THEN** 该行失败，提示切换生效日不得早于今天（防追溯改写历史核算，BR-4.1-18）

#### Scenario: 落入已失效历史阻断
- **WHEN** 切换日落在某已失效区间内
- **THEN** 该行失败并提示不可修改已失效历史，建议改用 链尾+1 或未失效段内切换

#### Scenario: 中间段插入自动失效日
- **WHEN** 链为 [A 段生效中] + [B 段 2027-07-01 起未生效]，切换日 2026-11-01 落 A 段内
- **THEN** 计划：缩短 A 至 2026-10-31 + 新建 [2026-11-01, 2027-06-30]（失效日自动=B 生效日-1 并回显）

### Requirement: 行级提交与结果报告
提交 MUST 按行独立执行且不回滚成功行：缩短动作调用税码变更能力（变更原因自动生成，含所选政策文号，入快照与 `MDM.TAXCODE.UPDATED` 事件）、新建动作调用税码创建能力（**新段政策文号 MUST 自动=所选政策**，快照与 `MDM.TAXCODE.CREATED` 逐行生成）；同税码一行内的缩短与新建 MUST 顺序执行（先缩短后新建，新建失败时该行标记部分失败并给出已完成动作说明，**MUST NOT 回滚已执行的缩短**——缩短本身使链更紧凑，无数据损害，行状态记 PARTIAL 供重试）。结果报告 MUST 含 `{rowNo, taxCode, result(SUCCESS/FAILED/PARTIAL), reason, actions:[{action, summary}]}` 与 total/succeeded/failed 统计；批次上限 500 行（422）。预检未通过的行 MUST NOT 被提交执行（提交端复验计划）。

#### Scenario: 部分失败不回滚
- **WHEN** 5 行中 1 行切换日落入历史而预检失败，提交其余 4 行
- **THEN** 4 行成功（各行生成缩短/新建快照与事件），失败行不执行且报告标红原因

#### Scenario: 新段政策文号自动带入
- **WHEN** 以政策 P 发起变更成功新建新段
- **THEN** 新段记录的政策文号为 P，且关联回链页可见该新段版本流水

#### Scenario: 超限阻断
- **WHEN** 提交 501 行
- **THEN** 系统 422 拒绝整批

### Requirement: 权限与页面接入
工作台与版本对比的全部写接口 MUST 要求 ROLE_ADMIN（403），候选/版本/对比查询须已认证（401）；页面挂载于菜单 1.6.2（`/m/1.6.2`），不新增菜单；ROLE_USER 视图 MUST 无「发起变更」「对比」之外的写提交能力（发起变更入口对非管理员隐藏）。

#### Scenario: 普通用户不可发起
- **WHEN** ROLE_USER 访问 1.6.2 且尝试调用工作台提交接口
- **THEN** 返回 403，无数据写入；页面上「发起变更」按钮不渲染

#### Scenario: 未认证查询被拒
- **WHEN** 未登录请求候选或版本接口
- **THEN** 返回 401
