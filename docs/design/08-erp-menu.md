# ERP 系统层次化功能菜单清单


**生成日期**：2026-09-30（四字命名优化版）
**用途**：作为系统导航菜单、功能盘点与验收覆盖检查的基准清单。

## 命名规则

| 规则 | 说明 |
| --- | --- |
| 四字优先 | 二级、三级菜单统一使用四个汉字；一级菜单亦以四字为目标 |
| 复杂拆分 | 单条菜单承载多逻辑时，拆分为多条并列菜单（如"扫码出入库"拆为收货/上架/拣货/发货/盘点扫码） |
| 语义转写 | 英文缩写（BOM、MRP、ATP、IQC、EVT、WBS、SLA、UAR 等）按语义转写为四字中文，对照见附录二 |
| 追溯保留 | 每个一级菜单标注规格章节号，完整对照见附录一 |

## 层级说明

| 层级 | 含义 | 来源依据 |
| --- | --- | --- |
| 一级菜单 | 业务域 / 平台域 |  |
| 二级菜单 | 域内功能模块（四字） | 各域"业务范围 / 核心业务能力"条目 |
| 三级菜单 | 功能点 / 场景入口（四字） | 各域业务流程与典型业务场景 |

## 备注

1. 全部二级、三级菜单均为四字；英文缩写类功能已按语义转写为四字中文（对照见附录二），保证导航文案统一。
2. 复杂功能已按操作对象拆分为多条菜单，例如：扫码作业拆为收货/上架/拣货/发货/盘点扫码；试产拆为工程/设计/量产试产；凭证管理拆为签发/轮换/吊销/追溯。
3. 菜单顺序按"数据 → 供应链 → 制造质量 → 财税资产 → 人力项目 → 协同移动 → 分析 → 平台"的业务价值链排列，实际导航可按角色权限裁剪。
4. 全局卡控（C-0-xx）、全局配置参数（4.0.3）与卡控级别（4.0.1）为横切能力，不单设菜单，体现在各功能点的审批/阻断交互中。
5. 各域"异常与边界"场景（超信用冻结、效期锁定、盘点差异等）以状态标记、告警或待办形式挂在对应三级菜单下，不单独列项。
